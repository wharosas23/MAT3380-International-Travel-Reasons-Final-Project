# MAT3380-International-Travel-Reasons-Final-Project

Link to shiny app project: https://wharosas64.shinyapps.io/Final-Project-WHAR/

For my Introduction to Data Science class, I developed an interactive web application using R to explore global tourism trends through data visualization. The focus of this project is on international travel patterns, specifically examining how tourism varies across countries, purposes of travel, and regions over time. The goal is to recreate and adapt professional-level visualizations while enhancing them with interactivity and clarity.

The project is inspired by three visualizations sourced from Our World in Data, all centered around tourism. These include:

- A world map showing international trips for personal reasons across countries and years.

- A scatterplot-style interactive graph comparing personal versus business travel by country and continent.
  <img width="500" height="350" alt="image" src="https://github.com/user-attachments/assets/60fa5ba5-94dc-4e27-b18f-b8e6df03f596" />

- A time-series visualization displaying international tourist arrivals by region of origin.
  <img width="500" height="350" alt="image" src="https://github.com/user-attachments/assets/272e6a6e-03fe-49b3-8797-b90bae7ebbad" />

A key strength of these visualizations is their interactivity. Features such as hover-based tooltips, sliders for selecting time ranges, and filtering by country or region provide deeper insight into the data. To recreate these visualizations, the dataset will include variables such as:

- Country or region
- Year
- Number of international trips (personal and business)
- Tourist arrivals by region

Using these variables, I was able to recreate two of the visualizations listed above and display them through the Shiny app (link provided at the top).
